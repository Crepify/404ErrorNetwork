# 404ErrorNetwork

### The home of 404 Error Found.

Some teams are remembered for what they build. Others are remembered for how it feels to build together. **404 Error Found** is about both.

404ErrorNetwork brings our people, projects and shared story into one place. It is a home for the work we care about and a reminder of the team we would choose again.
